# Chattify – Realtime Chat Application

Chattify is a full-stack real-time chat application built using the **MERN Stack** and **Socket.io**.  
It supports instant messaging, group chats, real-time notifications, typing indicators, and seamless chat UI.

---

##  Features

 **Authentication**
- User registration & login (JWT Authentication)
- Secure password hashing with bcrypt
- Private route protection

  **Real-Time Chat**
- One-to-one messaging
- Group chat creation and management
- Message timestamps



 **Group Chat**
- Create groups
- Rename group
- Add & remove users
- Group admin support

 **Modern UI**
- Responsive design
- Sidebar with users & conversations
- Beautiful chat interface

---

 **Tech Stack**

 **Frontend**
- React.js
- Redux Toolkit
- Socket.io-client
- React-Bootstrap

 **Backend**
- Node.js
- Express.js
- MongoDB & Mongoose
- Socket.io
- JWT Authentication
